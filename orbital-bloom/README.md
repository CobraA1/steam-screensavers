# Orbital Bloom

A passive WebGL screensaver built with locally vendored Three.js r186 for Steam Deck.

It starts automatically, contains no input handling, follows display resolution changes, and clamps frame hitches. Edit `config.js` to change motion, particle density, camera drift, fog, exposure, or the pixel-ratio cap.

Three.js is stored in `vendor/`, so the screensaver needs no network connection at runtime.
