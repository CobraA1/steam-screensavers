What is this measuring, and what is the offscreen tradeoff?

Normal alpha: ordinary semi-transparent shapes are drawn individually; intersections can accumulate opacity or sort incorrectly.

Alpha hash: meshes discard a fraction of fragments according to opacity and write depth normally. It can reduce sorting/overlap artifacts but causes visible grain without temporal smoothing.

Offscreen composite: shapes are drawn opaque into one transparent-background render target with depth testing, then the resulting texture is faded once over a background. Overlaps never double-blend, but inner/hidden shapes cannot show through the front shapes, and this 2D compositing technique does not solve 3D occlusion by unrelated live scene objects.

All views use the same models, positions, camera and opacity; the offscreen view intentionally shows the visible surface of a group, not physically translucent layers. The three-view comparison performs more work than a single mode: use the Display selector to compare each mode’s frame rate in isolation.

Most browsers cannot disclose actual process RAM use or VRAM usage. The JS heap is shown only when performance.memory.usedJSHeapSize is available (typically Chromium; it excludes other browser memory). GPU bytes are a lower-bound allocation estimate for attribute buffers plus explicitly created offscreen RGBA8 color and depth buffers; actual usage also includes browser framebuffers, driver alignment, compiled shaders, caches, and other resources.
